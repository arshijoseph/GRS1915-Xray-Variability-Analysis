# GRS 1915+105 X-ray Variability Analysis

This repository contains the Python code developed for my MSc Data Science dissertation project on the automated detection and cataloguing of X-ray variability states in the black-hole X-ray binary GRS 1915+105.

## Project Overview

GRS 1915+105 is known for exhibiting complex and highly variable X-ray behaviour. This project analyses observational data from the Rossi X-ray Timing Explorer (RXTE) to investigate and characterise different variability states.

The analysis includes data preprocessing, variability analysis, investigation of periodic and quasi-periodic behaviour, and methods for identifying characteristic variability patterns in the observations.

## Repository Contents

* `grs1915_variability_analysis_code.py` — Main Python script containing the data processing and analysis pipeline.

## Main Analysis

The Python workflow includes:

* Loading and preprocessing RXTE observational data
* Construction and analysis of X-ray intensity and colour measurements
* Exploration of variability patterns
* Periodicity analysis of observational segments
* Investigation of candidate variability states
* Generation of diagnostic plots and analysis outputs

## Technologies

The analysis was implemented in Python using scientific computing and data-analysis libraries.

## Data

The observational data used in this project are derived from archival RXTE observations of GRS 1915+105.

The full observational dataset is not included in this repository because of its size. The repository contains the analysis code used to process and investigate the data.
